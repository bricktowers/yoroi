# Examples

Apps in this folder are **not** Yarn 1 / Lerna workspaces. Each example owns its package manager and lockfile. Do not add them to root `package.json` `workspaces` or `lerna.json`.

- [`yoroi-demo`](./yoroi-demo): Expo dev-client that deposits and withdraws preprod ADA via `yoroi://` deep links. Yarn 4.
